# Product Context

## 해결하는 문제

- 정적 홈페이지에는 방문자와의 양방향 소통 수단이 부족함
- 전통적인 방명록은 새로고침 없이는 최신 글을 볼 수 없음
- 별도 API 서버 구축·운영 부담

## 사용자

| 역할 | 설명 |
|------|------|
| 방문자 | 이름과 메시지를 남기고 다른 사람 글을 실시간으로 확인 |
| 사이트 운영자 | (초기) 별도 UI 없이 Supabase 대시보드로 데이터 관리 |

## 사용자 경험 목표

1. **즉시성**: 글 작성 후 목록에 바로 표시 (Realtime)
2. **단순함**: 최소 입력(이름, 메시지)으로 빠른 작성
3. **가독성**: 시간순 목록, 명확한 타이포·여백
4. **모바일 우선**: 작은 화면에서도 편한 입력·스크롤

## 주요 기능 (예정)

- 방명록 작성 폼 (이름, 메시지, 유효성 검사)
- 방명록 목록 (최신순 또는 작성순)
- 실시간 새 글 수신 (Supabase Realtime `postgres_changes`)
- 로딩·에러·빈 상태 UI
- (선택) 글자 수 제한, 스팸 완화( rate limit / RLS )

## 성공 기준

- 새 글 작성 시 1초 이내 다른 클라이언트에 반영
- Lighthouse 접근성·성능 기본 점수 유지
- Supabase RLS로 읽기/쓰기 정책 명확히 정의
