# Project Brief

## 프로젝트 개요

Supabase를 백엔드로 사용하는 **실시간 방명록 웹사이트**입니다. 방문자가 이름과 메시지를 남기면, 다른 사용자 화면에도 즉시 반영됩니다.

## 목적

- 개인/소규모 홈페이지용 방명록 기능 제공
- 별도 백엔드 서버 없이 Supabase로 데이터 저장 및 실시간 동기화
- Next.js + Tailwind CSS 기반의 빠른 UI 개발

## 핵심 목표

1. 방명록 작성 (이름, 메시지) 및 목록 조회
2. Supabase Realtime으로 새 글 실시간 반영
3. 반응형·접근성을 고려한 깔끔한 UI
4. Vercel 등 정적/서버리스 배포에 적합한 구조

## 범위

### 포함

- Next.js App Router 기반 프론트엔드
- Supabase PostgreSQL + Realtime 연동
- 방명록 CRUD (최소: 생성, 조회; 삭제/수정은 정책에 따라)
- Tailwind CSS 스타일링
- 환경 변수 기반 Supabase 설정

### 제외 (초기 단계)

- 사용자 인증/로그인 (익명 방명록 우선)
- 관리자 대시보드
- 이미지/파일 첨부
- 다국어(i18n)
- 이메일 알림

## 비즈니스 가치

- 저비용·빠른 구축으로 방문자와 소통 채널 제공
- 실시간 피드백으로 참여감 있는 홈페이지 경험
- Supabase 생태계를 활용한 확장 가능한 기반
